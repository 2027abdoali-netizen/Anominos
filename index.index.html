الشروحات السيبرانية

الدرس الأول: ثغرة SQL Injection

ثغرة حقن أوامر SQL تحدث عندما يتم إدخال بيانات من المستخدم مباشرة إلى الاستعلام دون تنقيح.

SELECT * FROM users WHERE user = 'admin' AND pass = '' OR '1'='1';

الدرس الثاني: ثغرة XSS (Cross-Site Scripting)

تسمح للمخترق بحقن أكواد JavaScript خبيثة داخل صفحات الويب ليتم تنفيذها في متصفح الضحية.

<script>alert('XSS Payload!');</script>

اختبر مهاراتك الان

سؤال: ما الثغرة التي تمكن المخترق من قراءة قاعدة البيانات مباشرة؟
